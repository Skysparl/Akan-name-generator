# Akan Name Generator 🇬🇭

A responsive web application that calculates the day of the week a user was born and generates their corresponding traditional Ghanaian **Akan name**.

---

## 📅 Background

In Akan culture (Ghana), children are traditionally named after the day of the week they were born. These names carry cultural significance and reflect the personality traits associated with each day.

| Day of the Week | Male Name | Female Name |
| |
| Sunday:             | Kwasi | Akosua |
| Monday:             | Kwadwo | Adwoa |
| Tuesday:            | Kwabena | Abenaa |
| Wednesday:          | Kwaku | Akua |
| Thursday:           | Yaw | Yaa |
| Friday:             | Kofi | Afua |
| Saturday:           | Kwame | Ama |

---

## ✨ Features

* Interactive Form: Accepts birth day, month, year, and gender input.
* Strict Date Validation: Handles leap years and invalid calendar dates (e.g., prevents Feb 30 or April 31 entries).
* Dynamic Results: Displays the calculated birth day and Akan name dynamically without reloading the page.
* Reset Functionality: Easily toggle back to the form to generate another name.
* Clean Responsive UI: Designed with modern Flexbox layouts and styled for all screen sizes.

---

## 🛠️ Technologies Used

* HTML5: Semantic layout structure.
* CSS3: Custom styles, Flexbox layout, and responsive UI design.
* JavaScript (ES6): DOM manipulation, Date API calculations, and event handling.
